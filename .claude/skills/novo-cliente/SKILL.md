# Onboarding de Novo Cliente

Checklist estruturado para iniciar um cliente com profissionalismo e sem retrabalho.

## Etapas

### 1. Formalização (`juridico-empresarial`)
- Contrato de prestação de serviços revisado (escopo, honorários, reajuste, rescisão, confidencialidade/LGPD).
- NDA se houver troca de dados sensíveis antes do contrato.

### 2. Estrutura do projeto (`gestor-projetos`)
- Escopo escrito (incluído / excluído / critérios de aceite), cronograma com marcos, e canal de comunicação combinado.
- Criar estrutura de pastas do cliente (padrão: `Cliente/01-Contrato`, `02-Dados-Recebidos`, `03-Analises`, `04-Relatorios`, `05-Reunioes`).

### 3. Lista de documentos e acessos (`gestor-projetos` + `contador-fiscal`)
Solicite ao cliente, por escrito, com prazo:
- Demonstrações contábeis dos últimos 2-3 anos (Balanço, DRE, balancetes).
- Extratos bancários e faturamento detalhado do período.
- Regime tributário, contrato social e organograma.
- Acessos necessários (sistema de gestão, contabilidade online) — com registro formal de autorização.

### 4. Diagnóstico inicial (skill `analise-completa`)
- Rode o fluxo de análise completa com os dados recebidos — este é o entregável de abertura que demonstra valor logo no início.

### 5. Reunião de kickoff (`assistente-executivo` + `redator-executivo`)
- Agendar kickoff; preparar pauta: apresentação do diagnóstico inicial, plano de trabalho, ritual de acompanhamento (ex.: reunião mensal de resultados), pendências.
- Ata com decisões e ações registrada e enviada ao cliente.

## Regras
- Nenhum trabalho técnico começa sem contrato assinado e escopo aceito por escrito.
- Todo dado recebido do cliente é registrado (o quê, quando, de quem) — protege ambos os lados.
- Prazos internos contam a partir do recebimento completo dos documentos, e isso fica claro para o cliente desde o kickoff.
